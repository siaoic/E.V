# 播报完成事件与自持续发言循环

对标 Neuro-sama 的连续发言：说完一句接一句、冷场时自聊。新增「播报开始事件」与「播报完成事件」，二者都是播报管线（本系统插件，TTS 引擎可为外部进程）发出的 World 事件。播报开始事件开启一个裁决窗口，让她预生成下一句；播报完成事件只推进待播队列，不开窗。由此形成「裁决 → speak → 播报开始 → 再裁决（预生成下一句）→ 播报完成 → 接上下一句」的自持续循环，发言节奏由播报时长天然限速，不引入本地定时器，ADR-0001 的零定时器约束不变。

speak 回执只更新状态水位与记忆，不开窗。播报开始事件开启裁决窗口，让她预生成下一句；播报完成事件只推进待播队列，不开窗。这样每句话只有一次裁决机会，让裁决与播报流水线化，听感无缝。

发言守门职责随之从限频转为防退化：与近期发言的重复度、内容过滤；拒绝后不安排定时重试。播报开始事件只在待播队列为空时开窗，待播队列不丢弃、不清空。插话机制已移除（见 ADR-0006 的废弃说明）。

沉默仍是合法稳定态；连续发言的人格倾向由宪法种子与话题池承担，不由机制强制。完全静默不触发发言的约束不变——直播进行中事件流（心跳、游戏事件、播报事件）几乎不断，死寂只出现在停播后。
