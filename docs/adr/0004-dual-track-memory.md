# 双轨记忆：文件工作区为人格权威，A_Memorix 为语义索引

Status: 已实现（2026-10-10）：文件工作区轨全量落地——宪法种子常驻前缀、每窗口召回注入、记忆工具协议（note_*/git_*/persona_*/memory_forget/recall_viewer）、Git 版本历史（缩水回执兜底）、观众档案机械唤起、dream 后台整理。与设计的差异：无审批面（Git 历史 + 缩水回执替代，见 docs/计划.md）；语义索引轨为内置向量+bigram 而非 A_Memorix（接入仍待 D3）

人格的连续性由文件工作区（纯文本笔记 + Git 版本历史）定义，这是唯一的人格权威载体。A_Memorix 只承担语义索引与联想检索：Episode、向量与图谱关联、画像，不承载人格叙事。两条轨道都经 Persona 插件的记忆工具协议写入，工作区文件工具与 A_Memorix 索引写入是两条独立授权面，分别过审批。

代价：两套存储需要保持一致性，工作区的覆写与删除需要版本历史与最小权限校验来兜底。
