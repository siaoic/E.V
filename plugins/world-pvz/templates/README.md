# PvZ 模板标定说明（必读）

本目录的模板 PNG **无法随插件分发**（各版本游戏的 UI 有差异），必须在本机
实机截取一次。模板缺失时插件会拒绝加载并列出缺哪些文件，这是刻意设计：
用错误模板做识别会产出错误的直播行为，比不能加载更糟。

## 截取步骤

1. 把游戏窗口调整到 `config.toml` 里 `base_resolution` 指定的尺寸
   （默认 800×600，含客户区边框时的实际客户区大小）。
2. 依次进入以下画面，用任意截图工具按【基准分辨率的原尺寸】截取对应区域，
   保存为本目录的 PNG（文件名必须完全一致）：

| 文件名 | 内容 | 截取画面 |
| --- | --- | --- |
| `phase_main_menu.png` | 主菜单特征区（标题/按钮） | 主菜单 |
| `phase_seed_select.png` | 选卡界面特征区 | 选卡界面 |
| `phase_battle.png` | 战斗画面特征区（顶栏/铲子） | 战斗中 |
| `phase_level_complete.png` | 结算画面特征区 | 过关结算 |
| `digit_0.png` ~ `digit_9.png` | 阳光计数器的数字 0~9（每一位） | 战斗中，阳光数字区放大截图后裁切 |

3. 同时核对 `config.toml` 里的区域坐标（`lawn_rows` / `card_slots` /
   `sun_region` / `grid_origin` / `grid_cell`），它们也在同一基准坐标系下，
   可用任意看图软件读出像素坐标填写。

## 校验

重新加载插件：模板齐全时日志出现「PvZ 模板已加载 14 张」即成功；
缺哪个文件会在报错里直接列出。运行中把 `card_ready_brightness` /
`row_threshold` 按实际画面微调（战斗中卡片冷却时调低亮度阈值，
僵尸进入草坪时观察「第 N 行有僵尸」是否准确）。
